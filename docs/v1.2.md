# v1.2 — Rotation, LJ experiments and scientific observables

## Delivered

- Native torque-free rigid rotation from atomic point-mass inertia, principal-axis
  thermal angular momentum, normalized quaternions and bounded Lie-midpoint steps.
- World-frame angular momentum and angular velocity, per-atom `v_COM + omega × r`,
  Rust/headless action plus additive C ABI/Python/C# angular controls.
- Topology rebuilds preserve surviving atom coordinates/velocities exactly,
  including atomistic deformation. Backend kind and observables are explicit contracts.
- Portable viewer switches atomically between Native water/methane/benzene and
  single-species generic LAMMPS LJ. Failure leaves the previous simulation intact;
  no fallback is labeled as LAMMPS. Modes retire IDs and advance topology versions.
- KE/PE/total energy, measured temperature, degrees of freedom and energy change.
- f64 reset initial state/parameters/seed and step-tagged action log export;
  sampled render trajectories (up to 1000 frames) with local JSON import/scrubbing.
- Lightweight and LAMMPS-inclusive Windows x64 archives, licenses and corresponding
  source archive. Both EXE and bundled runtime use static CRT, system DLLs only.

## Physical definitions and limits

Native inertia is `sum m (r² 1 - r rᵀ)` about the mass COM, amu Å². Its symmetric
Jacobi eigensolver provides principal moments, axes and a pseudoinverse. Point
particles have 0 rotational DOF, linear molecules 2, nonlinear templates 3.
World angular momentum remains constant without torque. Body angular velocity
changes for an asymmetric top; a constant arbitrary angular velocity is not
incorrectly imposed. Quaternion midpoint uses 12 fixed iterations with an
angular increment bound of 0.01 rad per internal substep. Rotational energy is
approximately conserved, with convergence tested as dt decreases. No rigid
rotation creates internal stretching, vibrations or conformer changes.

Independent Gaussian COM and principal angular-momentum samples obey
`var(v)=kBT/M`, `var(L_i)=kBT I_i`. Zero temperature zeros both. There is no
thermostat, COM subtraction, streaming correction or exact rescaling. Measured
Native temperature uses total translational+rotational KE and `3N + sum(rank I)`
DOF. COM Maxwell samples retain the v1.1 seed sequence; angular samples use a
separate deterministic stream. Seed reproducibility is guaranteed within the
same executable/configuration; transcendental math is not promised bitwise equal
across hardware or operating systems.

Collisions/walls remain elastic, frictionless conservative bounding-sphere
impulses. Contact normals go through COM, so there is **no collision torque**,
no exchange of rotational/translational energy and no atomistic interactions.
Dense multi-contact correction can leave residual overlap. Native has no
potential-energy model: PE and total are unavailable, never invented as zero.

LJ preset: generic particles of mass 12.011 amu (not a carbon force field),
ε=0.1 kcal/mol, σ=3.4 Å, cutoff=8.5 Å, energy shifted at cutoff, 40 Å box,
NVE velocity Verlet, dt=0.1 fs, reflected fixed walls, initial 100 K, seed 42,
50 particles. Reflecting walls have lower-order energy behavior at wall events;
energy convergence tests exclude wall events. A shifted potential leaves the
force discontinuous at cutoff. No charges or molecular force field is implied.
LAMMPS `get_thermo` returns PE, KE and temperature after `run 0 post no`; its
`thermo_temp` uses `extra/dof 0` to report the same 3N convention, including net
flow. Tiny differences from Native conversion constants reflect LAMMPS's own
`units real` constants. See [official thermo API](https://docs.lammps.org/Library_properties.html)
and [lj/cut definition](https://docs.lammps.org/pair_lj.html).

ΔE (or Native ΔKE) is relative to the first observation after the latest
state-changing user action. Pause/speed do not reset it. This is an absolute
energy change, not a normalized drift rate or an accuracy certificate.

Export is an experiment record, **not a general restart format**. The initial
f64 state is taken at reset. The action log records subsequent operations with
physical step numbers (10000 event cap). Recording-start metadata is also kept;
render frames use f32 positions/velocities and browser observation timing, may
skip physical steps, and may span topology changes. Replay does not reintegrate
or alter the Rust world. Imported JSON is bounded to 50 MB/1000 frames with
coordinate/index validation. Live simulation pauses before replay; returning
keeps it paused. Long unbounded recording, restart import and exact checkpoint
restoration remain future work.

## Build and verify

```powershell
node tests/trajectory.mjs
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
cargo test --all-features
cargo build --release
powershell -ExecutionPolicy Bypass -File scripts/test-bridge.ps1
python tests/dll_smoke.py target/release/mol_engine_core.dll
python tests/python_headless.py target/release/mol_engine_core.dll
powershell -ExecutionPolicy Bypass -File scripts/build-viewer.ps1
python tests/viewer_smoke.py TerraMol.exe
# Optional runtime: build from the pinned source, or place a compatible DLL beside EXE.
powershell -ExecutionPolicy Bypass -File scripts/build-lammps-runtime.ps1 -Source artifacts/lammps-min/lammps-stable_29Aug2024_update3
$env:LAMMPS_LIBRARY=(Resolve-Path liblammps.dll).Path
cargo test --features lammps --test lammps -- --ignored --test-threads=1
cargo test --features lammps --lib -- --ignored --test-threads=1
python tests/viewer_smoke.py TerraMol.exe --lammps
python scripts/package-viewer.py --with-lammps
python scripts/package-source.py
```

The smoke test without `--lammps` expects no runtime (unset LAMMPS_LIBRARY and
use an EXE directory without the DLL); the full mode test expects the runtime.
Close running viewer instances before overwriting their EXE or DLL on Windows.

## Executed acceptance

Local Windows: default tests 21 passed; all-feature tests 25 passed / 4 explicitly
opt-in tests ignored by default. The 4 opt-in LAMMPS tests were separately run
against the static-CRT runtime and passed: analytic force/potential, NVE drift
and dt convergence, mapping/state/rebuild/reproducibility, FFI lifecycle and
C-API error conversion. Actual DLL Python/C# lifecycle/layout pass. Strict
Clippy and formatting pass. Portable HTTP tests cover controls, missing-runtime
failure, full LJ mode, bonded-molecule rejection, mode-switch IDs, export metadata,
concurrent reads, shutdown and idle exit. Browser tested download of 89 frames,
local re-import and scrub to frame 89; WebGL and model/observable controls verified.

Unity Editor/IL2CPP, macOS LAMMPS, validated water force fields, thermostat ensembles,
conformer search and RL training are not verified or delivered by this milestone.
Cross-platform CI status is recorded in release notes after execution.
